# Каталог ассетов (ГДД, раздел 5) → реализация

Все 3D-объекты сейчас собраны процедурно из деталей Roblox (Part/WedgePart/SpecialMesh) — код в
`src/server/World/Models/`. Это «серые» модели-заглушки, которые полностью рабочие в игре; художник может
заменить любую из них на свою MeshPart-модель, сохранив имя функции-строителя (ключ `model` в
`src/shared/Config/Items.luau`).

Обозначения: ✅ — реализовано отдельным объектом/функцией, 🧩 — входит в состав другой модели,
◻ — резерв (в ГДД есть, в игру пока не добавлен: хорошие кандидаты на будущие обновления).
